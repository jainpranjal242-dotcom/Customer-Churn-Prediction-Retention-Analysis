# Customer Churn Prediction & Retention Analysis
**Prepared by: Pranjal Jain**

## Contents
- `customer_churn_raw.csv`: synthetic dataset with missing values and duplicates.
- `customer_churn_cleaned.csv`: duplicate-cleaned dataset with numeric churn flag.
- `Customer_Churn_Prediction_Retention_Analysis.ipynb`: EDA, preprocessing, Logistic Regression, Decision Tree, Random Forest, metrics, confusion matrix, ROC-AUC, feature importance, prediction function, and retention recommendations.
- `Project_Report_Pranjal_Jain.pdf`: project report.
- `requirements.txt`: dependencies.

## Run
Install Python 3.10+, run `pip install -r requirements.txt`, open the notebook in Jupyter or VS Code, and execute cells in order.

Note: data is synthetic for educational purposes, not the IBM Telco dataset or real customer data.
